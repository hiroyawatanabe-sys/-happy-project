## 1. 共通仕様（全図解に適用）

| 項目 | 仕様 |
|---|---|
| **形式** | 原則 **HTML + CSS**（インラインSVGは記号・アイコンのみ）。画像ファイルにしない |
| **理由** | ①LINE内ブラウザで確実に描画される ②テキストが選択・検索・読み上げ可能 ③レスポンシブが破綻しない ④文言修正が原稿差し替えで済む |
| **色** | 8色トークン（`--o-r-colors-*`）＋セマンティック色（`--c-success` `--c-error` `--c-warning`）のみ。**セマンティック色は8色から派生させない**（禁則3） |
| **NG/OKの表現** | NG＝`--c-error`（赤0°）／OK＝`--c-success`（緑145°）。この対応は全図で固定 |
| **角丸・余白** | `--ti-rb:4px` / `--ti-rc:8px` / `--ti-spc:20px`（トーン13：形状2＝直線寄り） |
| **レイアウト** | SPは縦積み（1カラム）、768px以上で横並び。矢印はSPで下向き（`rotate: 90deg`）に切り替える |
| **文字サイズ** | 図中の本文 1.3rem 以上、ラベル 1.2rem 以上。**1.1rem未満を使わない** |
| **コントラスト** | 図中のすべての文字で **4.5:1 以上**（`tools/` の検査対象に含める） |
| **代替テキスト** | `<figure>` + `<figcaption>` で図番号と内容を明示。装飾SVGは `aria-hidden="true"` |
| **横スクロール** | 図が画面幅を超えない。超える場合は `overflow-x:auto` を図の**内側**に持たせる |
| **印刷** | `@media print` で崩れないこと（商談でPDF化する運用があるため） |

## 7. 制作依頼時のチェックリスト

- [ ] HTML/CSSで実装しているか（画像ファイルにしていないか）
- [ ] SPで横スクロールが発生していないか
- [ ] 図中の全文字が 4.5:1 以上か
- [ ] NG＝赤・OK＝緑の対応が全図で一貫しているか
- [ ] `<figure>` + `<figcaption>` で図番号がついているか
- [ ] 装飾SVGに `aria-hidden="true"` があるか
- [ ] 印刷時に崩れないか
- [ ] 図に載せた数値が `docs/cta-lp-copy.md` の数字規約と一致しているか
